
# RevoU Coding Camp Projects

This repository contains the projects and exercises I completed during the **RevoU Coding Camp** (11 August 2025).

## Topics Covered
- JavaScript fundamentals
- HTML & CSS
- Web development exercises
- DOM manipulation
- Event handling

## Projects

### 1. Mini Calculator
- Simple calculator app built with JavaScript
- Features: addition, subtraction, multiplication, division
- Folder: `mini-calculator/`

### 2. To-Do List App
- Task manager app with add, delete, and complete features
- Uses localStorage to save tasks
- Folder: `todo-list-app/`

### 3. Personal Website Practice
- Basic personal website layout
- Responsive HTML & CSS
- Folder: `personal-website/`

## How to Run
Open the `index.html` file in each project folder with your browser.
